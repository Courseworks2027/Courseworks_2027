## Правила (кратко)

1. Своя ветка — `team-XX`. В `main` и чужие ветки не пушим.
2. Файлы проекта кладём в папку `teams/team-XX/`.
3. Осмысленные коммиты: `feat: добавил авторизацию`, а не `fix`, `123`.
4. Сдача — Pull Request из `team-XX` в `main`.
5. `git push --force` и `git push --all` запрещены.

Подробности — в [CONTRIBUTING.md](CONTRIBUTING.md).
